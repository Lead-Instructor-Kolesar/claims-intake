The shortest case (E12) used 228 input tokens and finished in 2436 ms, while the longest case (E11) used 274 input tokens and took 4557 ms. Latency nearly doubled even though input tokens rose by only about 20 percent, because E11 also generated more than twice as many output tokens. A short document therefore understates model workload: token use and latency grow with both document length and the size of the model’s answer, so a portfolio estimate cannot be scaled from the shortest case alone.
